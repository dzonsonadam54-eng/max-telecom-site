# MAX Telecom Components — сайт

Статический сайт официального дилера KOSCAB в Казахстане. Языки: казахский (основной), русский, английский.

## Файлы
- `index.html` — весь сайт (разметка, стили, скрипт, тексты на трёх языках)
- `logo-max-dark.png` — логотип
- `cert.jpg` — сертификат дилера KOSCAB (блок «Партнёры» внизу)
- `partner-kab.jpg` — письмо о партнёрстве с заводом КАВ (блок «Партнёры» внизу)
- `favicon.svg` — значок вкладки
- `vercel.json` — заголовки безопасности и кэширование для Vercel

## Где менять
- Телефон: в `index.html` строка `const CONTACT = {...}`; ссылка WhatsApp: `wa.me/77023899264`
- Тексты на языках: объект `const T = { kk: ..., ru: ..., en: ... }`
- Разделы продукции и их описания: массив `const CATS`

## Публикация на Vercel
1. Загрузить файлы в репозиторий GitHub (в Vercel указан Root Directory = max-telecom-site).
2. vercel.com → Add New → Project → выбрать репозиторий → Deploy (никаких настроек сборки не нужно).
3. Каждый новый коммит в репозиторий обновляет сайт автоматически.

## Наличие и цены из 1С
- `api/stock.js` — отдаёт сайту статусы наличия и розничные цены (без точного количества)
- `api/stock-upload.js` — принимает данные от 1С (схема, когда 1С стоит в офисе)
- `api/_lib/config.json` — сопоставление групп 1С с разделами сайта и пороги «мало»
- Инструкция для программиста 1С: `docs/1c-integration.md` в корне репозитория
- Демо блока наличия: открыть сайт с `?demo`
